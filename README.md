# Plantilla web para peluquerías y centros de estética

Plantilla de una página en negro y dorado suave para negocios de belleza.

**Vista previa:** https://carlosdev-demo2.netlify.app

## Cómo se usa
Los huecos entre corchetes (por ejemplo `[Nombre del negocio]`) se sustituyen por los datos reales del negocio y la web queda lista para publicar.

## Incluye
- Logo de ejemplo listo para cambiar por el del negocio.
- Servicios, opiniones de clientes y botón de llamar.
- Fotos de ejemplo de uso libre.

## Tecnología
HTML, CSS y JavaScript en un único `index.html`, sin dependencias. Tipografía: Jost.
`_headers` incluye `noindex` mientras sea una plantilla de ejemplo.

## Desplegar
Se publica la raíz del repositorio tal cual (sin build).
